# garagepro_sdk_usb
This is a repository for hosting GaragePro SDK library (Serial communication) for enterprise clients. Please contact us for further information at fix@carpm.in

## Release Notes (Only for stable versions)

### Version 1 (1.0)
First release of the GaragePro USB SDK. This contains two features - Read Fault Codes and Clear Fault Codes in any vehicle (Only full scan allowed)
